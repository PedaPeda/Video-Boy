Getting it onto a Game Boy

        
Game Boy and Game Boy Color: copy the .gb or .gbc file onto a flash cart with MBC5 support, for example an EverDrive GB, EZ-Flash Junior or an 8 MB repro flash cart.

        
Game Boy Advance: copy the .gba file onto a GBA flash cart (EverDrive GBA, EZ-Flash Omega …). It plays on the GBA, GBA SP and Game Boy Micro, on the DS and DS Lite with the flash cart in the GBA slot, and on a 3DS with custom firmware through open_agb_firm.

        
Nintendo DS: copy the .nds file to a DS flash cart's microSD card, or start it on a DSi or 3DS with TWiLight Menu++. The video plays on the top screen.

        
On every console: START pauses, SELECT restarts. Keep this tab in the foreground while converting; in the background the browser slows down playback.
